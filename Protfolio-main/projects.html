🤖 1. Agentic AI Lab (GenAI)

Build and manage AI agents and generative AI applications.

Agent Builder Create AI agents with custom capabilities, workflows, tool integrations, and knowledge bases. Configure LLM parameters (temperature, top-P/K, max tokens), system roles, and prompt templates with version control.
Agent Inference Real-time chat testing with streaming responses, file attachments, session management, tool usage tracking, guardrail status, and LLM output metrics.
LLM Hub Manage base and fine-tuned Large Language Models with comprehensive metadata. Fine-tune language models with custom datasets.
Guardrails System Input/output guardrails for content filtering, compliance checks, ethical guidelines, and custom rules. Create guardrail suites and bind them to agents.
Prompt Hub Create, organize, and manage reusable prompt templates with version control, tagging system, and inline editing.
Tool Hub Extensible tool system — HTTP, Web, Document Processing, Data Processing, Model Management, Security, Integration, Development, Monitoring, Data Analysis, and Orchestration tools. Custom tools via Python.
Knowledge Base (RAG) Create KBs with custom embedding models and chunking strategies. Upload documents, register custom retrieval functions, and configure RAG parameters.
Memory Management Three-tier memory: Session Memory (per chat), Agent Memory (persistent per agent), Organization Memory (shared across all agents).
Agent Test Suite Quality assurance with Exact Match, Regex, and Semantic Similarity evaluation. Batch testing, status tracking, and detailed pass/fail results.

API Management Live API endpoints for real-time predictions. Monitor API usage, response times, and error rates.
